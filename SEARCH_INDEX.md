## Short Description

VideoX Compressor is a Windows GUI application for reducing video file size. It focuses on recorded classes, tutorials, screen recordings, online meetings, lecture videos and other low-motion videos. It uses FFmpeg and FFprobe internally and can try hardware acceleration when supported by the system.

## Main Features

- Windows graphical user interface
- Hardware-accelerated video compression
- NVIDIA NVENC support when available
- Intel Quick Sync / QSV support when available
- AMD AMF support when available
- CPU fallback when hardware acceleration is not available
- Smart Size Target for already-compressed videos
- File queue with removable input files
- GPU Quality slider
- CPU CRF slider
- Final compression report
- Device ID based activation
- Diagnostic logs and bug reports
- Legacy NVIDIA FFmpeg fallback for older NVIDIA drivers
