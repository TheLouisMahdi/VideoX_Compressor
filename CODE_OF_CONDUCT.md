# Code of Conduct

## Our Pledge

We want the VideoX Compressor project space to be respectful, practical and helpful for users, testers and contributors.

Everyone is expected to communicate professionally, report issues clearly and avoid harassment, insults, spam or abusive behavior.

## Expected Behavior

- Be respectful and patient.
- Use clear language when reporting bugs.
- Provide useful technical details when possible.
- Respect that this project is still in beta.
- Do not share another user's private information.
- Do not post license keys, private Device IDs, personal documents or sensitive logs publicly.

## Unacceptable Behavior

- Harassment, insults, threats or personal attacks.
- Spam, unrelated advertising or repeated low-effort posts.
- Sharing malware, suspicious executables or unofficial modified builds.
- Publishing another user's private license key, Device ID, email, phone number or personal data.
- Abusing GitHub Issues for non-project-related messages.

## Reporting Problems

If you see behavior that violates this Code of Conduct, contact the maintainer.

Maintainer contact:

```text
Telegram: @thelouis_mahdi
```

For technical bugs, please use the bug report issue template and remove sensitive information before posting.

## Enforcement

The maintainer may remove inappropriate content, close issues, block users or take other reasonable actions to keep the project safe and useful.

## Scope

This Code of Conduct applies to project spaces including GitHub Issues, Pull Requests, discussions and official project communication channels.
