## 🇬🇧 English

**VideoX Compressor** is a practical Windows application for reducing video file size without dealing with complex FFmpeg commands.

It is designed for students, teachers, content creators, online course makers, office users, and anyone who needs to compress large videos quickly and easily.

### ✨ Key Features

| Feature | Description |
|---|---|
| Simple GUI | Easy Windows interface for everyday users |
| Bilingual UI | Persian and English interface |
| FFmpeg Engine | Reliable compression powered by FFmpeg |
| GPU Acceleration | Uses NVIDIA NVENC when available |
| CPU Fallback | Automatically works with CPU if GPU is not available |
| Multiple Formats | Supports common input formats and outputs MP4, MKV, MOV, WEBM, AVI |
| Custom Settings | Workers, height, FPS, audio bitrate, quality and output folder |
| Estimated Time | Shows estimated processing time |
| Device Activation | License activation based on Device ID |

### ⚙️ GPU / CPU Behavior

- For `mp4`, `mkv`, and `mov`, GPU mode is used if a suitable NVIDIA card is available.
- For `webm`, CPU mode is used.
- For general use, `mp4` is recommended.

### ✅ Recommended Settings

```text
Workers: 1
Height: 1080
FPS: 24
Output Format: mp4
GPU Quality: 32
CPU CRF: 30
Audio Bitrate: 32k
Audio Channels: 1
```

<a id="activation"></a>

### 🔐 Activation

After opening the software, the app shows your **Device ID**.

Send the Device ID on Telegram:

```text
@thelouis_mahdi
```

After verification, you will receive a `license.key` file.

Place `license.key` next to `VideoX.exe` or select it from inside the app.

### 🚀 How to Use

1. Download `VideoX_Compressor_v1.0.0.zip` from Releases.
2. Extract the ZIP file.
3. Run `VideoX.exe`.
4. Copy the Device ID.
5. Send the Device ID to `@thelouis_mahdi` on Telegram.
6. Receive `license.key`.
7. Place `license.key` next to the EXE file or select it inside the app.
8. Select your videos.
9. Select output folder.
10. Choose compression settings.
11. Click **Start Compress**.

### ⚠️ Important Notes

- Do not delete the `ffmpeg` folder.
- Do not delete the `_internal` folder.
- The license works only on the registered device.
- If the license expires, contact `@thelouis_mahdi`.
- This repository provides the public release package only, not the source code.
